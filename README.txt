MANUEL REMON - FREE GOOGLE-READY STATIC SITE

1. Create a free GitHub account at github.com if you do not already have one.
2. Create a new public repository, e.g. manuel-remon.
3. Upload EVERYTHING in this folder, keeping the assets folder.
4. In the repository: Settings -> Pages -> Deploy from a branch -> main -> / (root) -> Save.
5. Wait for GitHub Pages to publish the site.
6. Replace YOUR-GITHUB-USERNAME and YOUR-REPOSITORY in robots.txt and sitemap.xml with your real Pages address.
7. Open Google Search Console, add the exact Pages URL as a URL-prefix property, then submit sitemap.xml.
8. Use URL Inspection to request indexing for index.html, football.html and gallery.html.

IMPORTANT:
- Google decides whether and where pages/images appear; indexing is not guaranteed immediately.
- Keep the image files on the site and do not block them in robots.txt.
- Add more genuine pages and useful information over time rather than making many duplicate pages.
